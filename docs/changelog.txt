v1.25.5

- Added a Web UI so you can access jj-dlp from your phone or another pc on your wifi/network.  Steps to use:

    - Set a username and password in the WEB_UI_USER and WEB_UI_PASS fields

    - Login with the username and password you set.  You wont have to login again for 30 days (cookie expires).
    Note: Use the Web UI on your local network only. Access over the internet is not supported yet.
